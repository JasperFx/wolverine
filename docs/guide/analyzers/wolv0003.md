# WOLV0003: Cascading message tuple contains a Task or ValueTask

Every element of a tuple returned by a handler or an HTTP endpoint is a cascading message or a side effect. A `Task`
or `ValueTask` in the tuple is never awaited by Wolverine. It's treated like any other value in the tuple.

```csharp
public static class PlaceOrderHandler
{
    // WOLV0003: the Task in the tuple is never awaited
    public static (OrderPlaced, Task) Handle(PlaceOrder command, IEmailService email)
        => (new OrderPlaced(command.Id), email.SendConfirmationAsync(command.Id));
}
```

## How to fix it

Make the method async and return the tuple from it:

```csharp
public static class PlaceOrderHandler
{
    public static async Task<(OrderPlaced, OrderConfirmed)> Handle(PlaceOrder command, IEmailService email)
    {
        await email.SendConfirmationAsync(command.Id);
        return (new OrderPlaced(command.Id), new OrderConfirmed(command.Id));
    }
}
```
